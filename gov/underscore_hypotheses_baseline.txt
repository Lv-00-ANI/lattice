# gov/check_underscore_hypotheses.py baseline

# One line per (file, theorem). Format: <file>	<theorem>	<first binder>	<class>	<reason class>
#
# The class is `unused` (the proof does not mention the hypothesis) or `used` (the `_` prefix is a lie).
# The Fifth column is the REASON, added round 30 because the checker's own docstring required one and the
# baseline never carried it:
#
#   A-numeric-bound          the ordering hypothesis states the DOMAIN in which the bound holds; the proof
#                            may reach the bound without it, but the statement can be FALSE without it
#   B-equality-precondition  states the configuration the theorem is about (e.g. `decodePayload n rs = some c`);
#                            removing it would make the statement claim something about arbitrary inputs
#   C-signature-alignment    a data/function parameter kept so the signature matches the surrounding API
#                            (the file's doc says so -- see `RealTreeRecursion.eval_recursion_decreasing`)
#   D-typeclass              needed to state the proposition at all
#   F-assumption-predicate   a proposition the theorem presupposes (`Monotone act`, `Extract ts cs`,
#                            `IsRepresentative c W`) -- it describes the situation the theorem is about
#   E-other                  reported with its type so it can be argued with; every one of these is a
#                            REASON NOT YET ESTABLISHED and the gate prints the count separately
#
# ⚠ Round 30 measured the split rather than asserting it: see `agent-tmp/classify_unused_hyp.py`.
# An entry with `E-other` is a REASON NOT YET ESTABLISHED, and the gate prints those separately.
