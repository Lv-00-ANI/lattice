## 1. 实测：12 条链层定理的证明各引用多少内核声明

方法：剥注释后取证明体，统计其中出现的内核声明名（排除关键字）。
脚本 `agent-tmp/measure_chain_deps3.py`。

| 定理 | 引用的内核声明 |
|:--|--:|
| `decodePayload_encodeForm` | 5 |
| `compileProgram_sound` | **0** |
| `extract_compile` | **0** |
| `converges_within` | 1 |
| `loss_eq_zero_of_poly_eq_zero` | 2 |
| `residual_le_of_zero_on_dense` | 1 |
| `ladder_forward` | **0** |
| `sound_of_factors` | 1 |
| `scheme_covers_all` | 3 |
| `reinject_of_hold` | 3 |
| `decreases_of_one_step` | 1 |
| `absorbs_not_derivable` | 5 |

### 1.1 三条定理零引用，这是**好**的

`compileProgram_sound`、`extract_compile`、`ladder_forward` 的证明**完全不引用其他定理**：

| 定理 | 为什么零引用 |
|:--|:--|
| `compileProgram_sound` | 由 `Compiler.sound` 字段 + `List.mem_map` 的消解——**义务在结构里** |
| `extract_compile` | 就是 `Representation.roundtrip` 字段的定义展开 |
| `ladder_forward` | 就是 `Ladder.l2l3_sound` 字段的直接应用 |

**这不是「证明太空」，而是「义务被放在结构里」。**
这正是 `Ladder`/`Compiler`/`Representation` 三个结构的设计意图：
把该证的东西变成字段，于是使用它时**不再需要证**。

### 1.2 「组合」的真实含义

`PROOF-CHAIN-RUNG.md` 说链路由组合构成。**实测更精确**：

- **结构承担了大部分组合**（三个结构各带一条义务字段）；
- **定理层面只有少数真正的组合**：`scheme_covers_all`（引用 `realise`）、
  `reinject_of_hold`（引用 `Reinjection.loss_eq_zero_of_poly_eq_zero`）、
  `absorbs_not_derivable`（引用 5 个）。

⇒ 「组合而非重证」这个声称**成立**，但机制是**结构 + 字段**，不是**定理之间互相引用**。
这个区别重要：它说明为什么加一个新的约束类型**只需提供字段**，而不是重走一遍链路。

### 1.3 一个测量缺陷（第四次同类）

本轮第一次测量把注释也算进了证明体，于是 `exact`、`one`、`that` 这些英文单词被当作
引用；第二次修正后，多数定理却成了 0——因为正文提取的边界条件写错了。
第三次才是上表。

**这是第 7 次测量错误。** 全部由「换一种测量」纠正。记录在案。

## 2. 新规划：`ROADMAP-v9`

已被测量过的维度（覆盖度、承重性、否证、命名）**不需要再测**。
新规划换轴：**可否被使用**。

### 2.1 第一优先：链路的「使用说明」——`USAGE.md`

**问题**：库有 6,412 模块、~7,870 定理、9 份审计文档，但**一个外部使用者不知道从哪开始**。

**做什么**：一份 `USAGE.md`，包含：

| 内容 | 要求 |
|:--|:--|
| 四个结构（`Compiler`/`Representation`/`Ladder`/`Repair`）的最小实例怎么写 | 可直接编译的代码块 |
| 加一个新约束类型要做什么 | 逐步骤清单 |
| 每个入口点（`Geo.SampledBound`/`Reinjection`/`RepairConvergence`）证明什么 | 一句话 + 定理名 |
| 什么做不到 | 指向 `REFUTATION-CENSUS` |

**规模**：S–M。**为什么第一**：这是「通用基础设施」定位的**直接检验**——
如果无法被外部使用，定位就是空的。

### 2.2 第二优先：`Compiler` 结构的字段是否也构成义务

§1.1 发现三个结构的字段承担了义务。**但 `Compiler` 有 6 个字段，
`Representation` 有 8 个**——哪些是义务，哪些只是数据？

**做什么**：给每个结构的字段分类（义务 / 数据），并说明理由。
这直接指导「加新后端要提供什么」。

**规模**：S。

### 2.3 第三优先：把 §1 的依赖测量写成可重跑的检查

**做什么**：`gov/check_chain_deps.py`，报告 12 条链层定理的引用计数，
若某条**从 0 变成非 0** 或**从非 0 变成 0**，提示复查。

**规模**：S。**价值**：它是「组合而非重证」这条声称的守卫。
